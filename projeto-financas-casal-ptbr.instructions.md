description: 'Instruções para trabalhar neste projeto em português do Brasil e explicar erros/alterações claramente.'
---

- Este projeto deve ser trabalhado em português do Brasil.
- Ao analisar erros, explique em português:
  - qual é o problema;
  - por que aconteceu;
  - qual arquivo será alterado;
  - o que foi modificado;
  - como testar.
- Mantenha termos técnicos originais quando fizer sentido, como component, action, server action, schema, migration, route, build e deploy.
- Não alterar visual, banco de dados ou estrutura do projeto sem explicar antes.
